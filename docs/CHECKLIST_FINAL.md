# Checklist antes da apresentação

## Site
- [ ] Home abre sem erros.
- [ ] Busca encontra locais.
- [ ] Filtros funcionam individualmente e combinados.
- [ ] Detalhes de um local abrem corretamente.
- [ ] Avaliação pode ser enviada.
- [ ] Novo local pode ser cadastrado.
- [ ] Aumento/redução de fonte funciona.
- [ ] Alto contraste funciona.
- [ ] Teste em celular/responsivo.
- [ ] Remover/ajustar dados demonstrativos que não quiserem apresentar.

## GitHub
- [ ] Repositório criado.
- [ ] Dupla adicionada como colaboradora.
- [ ] Cada integrante sabe sua branch.
- [ ] `main` está funcionando.
- [ ] Commits têm mensagens claras.
- [ ] Alterações importantes foram revisadas.

## Apresentação
- [ ] Problema explicado em uma frase.
- [ ] Solução demonstrada pelo fluxo do usuário.
- [ ] Diferencial explicado.
- [ ] Tecnologias citadas.
- [ ] Limitações do protótipo assumidas.
- [ ] Evoluções futuras apresentadas.
- [ ] Demo do site testada antes de apresentar.
