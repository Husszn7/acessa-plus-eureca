# Guia dos slides — Acessa+

Use de 7 a 9 slides. O objetivo é contar uma história: problema → solução → funcionamento → impacto → protótipo → futuro.

## Slide 1 — Capa
- Acessa+
- Subtítulo: “Informação acessível para escolhas mais independentes”
- Nomes dos integrantes
- ETEC / turma / Eureca

Visual: mockup ou captura da Home ocupando boa parte do slide.

## Slide 2 — Problema
Explique o problema em uma frase grande:
> “Saber se um lugar é acessível não significa saber como ele é acessível.”

Mostre 3 exemplos de informações que podem faltar: entrada, banheiro, transporte/circulação, atendimento.

## Slide 3 — Proposta de solução
Mostre o fluxo:
Pesquisar → Filtrar necessidade → Ver recursos → Conferir informações → Avaliar experiência

Não encha de texto.

## Slide 4 — Público e necessidades
Apresente os principais perfis atendidos pelo protótipo:
- mobilidade reduzida
- deficiência visual
- deficiência auditiva
- necessidades cognitivas

Explique que o sistema não assume uma necessidade única; o usuário escolhe os filtros relevantes.

## Slide 5 — Como funciona
Coloque 3 telas lado a lado:
1. Busca
2. Resultado com filtros
3. Página do estabelecimento

Use setas para mostrar o caminho.

## Slide 6 — Diferencial
Título: “Não é só um mapa de lugares”
- mostra recursos específicos
- diferencia informação confirmada de não verificada
- recebe avaliações da comunidade
- permite cadastrar novos locais

## Slide 7 — Protótipo técnico
Mostre a arquitetura simples:
HTML → CSS → JavaScript → dados do protótipo

E cite as tecnologias usadas.

## Slide 8 — Impacto e evolução
Mostre o que pode crescer depois:
- integração com mapas reais
- contas de usuário
- banco de dados em nuvem
- validação por estabelecimentos
- rotas acessíveis
- painel para estabelecimentos

## Slide 9 — Fechamento
Frase final:
> “Acessibilidade também é poder escolher para onde ir com mais informação e segurança.”

Inclua QR Code para o protótipo, caso vocês publiquem no GitHub Pages.

## Visual
- Fundo claro e muito espaço em branco.
- Verde como cor principal, com detalhes em verde-limão suave.
- Fonte simples e grande.
- No máximo 4 ideias principais por slide.
- Use capturas reais do protótipo em vez de mockups genéricos.
