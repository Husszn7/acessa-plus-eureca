# Acessa+

Protótipo acadêmico desenvolvido por **Hitalo Luiz Rodrigues Moreira** e **Gustavo Henrique Souza Silva** para o projeto Eureca.

## Objetivo
Ajudar pessoas a encontrar lugares considerando necessidades específicas de acessibilidade, apresentando recursos disponíveis e informações compartilhadas pela comunidade.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- LocalStorage (MVP)
- Git/GitHub para colaboração

## Funcionalidades atuais
- Busca por local, categoria ou bairro
- Filtros de acessibilidade por necessidade e recurso
- 18 locais demonstrativos no catálogo
- Página de detalhes com recursos e avaliações
- Cadastro de novos locais
- Avaliação da comunidade
- Preferências de acessibilidade da própria interface
- Controle de tamanho de texto
- Alto contraste
- Contraste reforçado no texto
- Preto e branco
- Sublinhado de ações
- Redução de animações
- Modos visuais para protanopia, deuteranopia e tritanopia
- Interface responsiva

## Como executar
Abra o `index.html` em um navegador moderno ou use uma extensão como Live Server no VS Code.

> Os dados dos estabelecimentos são demonstrativos e ficam salvos no navegador durante o uso do protótipo.
